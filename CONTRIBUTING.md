# Изменения и предложения

Об ошибке можно сообщить через [Issues](https://github.com/Ddosena/blender-final-dimensions/issues/new/choose). Укажите версии Blender и расширения, шаги повторения, ожидаемый результат и фактическое поведение. Небольшая тестовая сцена полезнее большой рабочей; публикуйте только материалы, которыми можете делиться.

Для предложения функции объясните задачу пользователя и приведите пример ожидаемого измерения. Для геометрических измерений уточните направление, единицы и работу после модификаторов.

Для изменения кода создайте ветку и pull request. Сохраняйте отсутствие сторонних зависимостей и изменений исходного меша. Исправление расчёта сопровождайте численным примером; изменение мыши или отрисовки — проверкой в живом Blender. Запуск проверок и сборка описаны в [руководстве поддержки](docs/MAINTAINING_RU.md).

Предлагая код, вы соглашаетесь распространять его на условиях GPL-3.0-or-later, как и остальной проект.
