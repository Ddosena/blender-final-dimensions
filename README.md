**Размеры после модификаторов, сечения под мышью и линейки с привязкой к поверхности — прямо в Blender.**

Бесплатное открытое расширение для студентов и преподавателей. Для скачивания не нужен аккаунт GitHub. Python и дополнительные программы устанавливать не нужно; измерения работают без подключения к интернету.

![Две линейки на поверхностях после модификаторов](docs/images/rulers.png)

## Что умеет

| Функция | Для чего нужна |
| --- | --- |
| **Cage / Final** | Сравнить исходные габариты меша с результатом Subdivision, Bevel и других модификаторов. |
| **Delta / % / Half** | Увидеть изменение размера и половину итогового габарита по каждой мировой оси. |
| **e / f у выбранного ребра** | Узнать исходную длину ребра и полный габарит объекта после модификаторов вдоль его направления. |
| **Сечение под мышью** | Увидеть контур сечения и размер в направлении курсора: **f**, а также его половину **½**. |
| **Несколько линеек** | Поставить две точки на вычисленных поверхностях, измерить прямое расстояние **d** и добавить следующие линейки. |
| **Редактирование концов** | Выбрать линейку в списке, перетащить любой конец ЛКМ или снять его ПКМ и установить заново. |

Модификаторы применять не требуется. Измерение читает их результат с настройками **Viewport**, не изменяя исходный меш. Точки могут находиться на одном объекте или на двух разных Mesh-объектах.

## Установка в пять шагов

1. [Скачайте **final_dimensions.zip**](https://github.com/Ddosena/blender-final-dimensions/releases/latest/download/final_dimensions.zip). **Не распаковывайте** его.
2. В Blender откройте **Edit → Preferences → Add-ons**.
3. Нажмите маленькое меню со стрелкой в правом верхнем углу → **Install from Disk…** → выберите ZIP → подтвердите установку.
4. Найдите **Final Dimensions** в списке и проверьте, что галочка включения установлена.
5. Вернитесь к модели, наведите мышь на **3D Viewport**, нажмите **N** и выберите вкладку **Final Dimensions**.

**Впервые устанавливаете дополнение?** [Подробная инструкция](docs/INSTALL_RU.md) объясняет каждый шаг, обновление и удаление. Скачивайте установочный файл из **Releases / Assets**; кнопка **Code → Download ZIP** и файл **Source code (zip)** дают исходники, а не установочный пакет.

## Первое измерение

Нажмите **Add Ruler**, кликните по первой поверхности, затем по второй. Повторное **Add Ruler** создаёт следующую линейку, сохраняя остальные. Выберите строку в списке, чтобы редактировать её: **зажать ЛКМ возле конца** — перетаскивать, **ПКМ возле конца** — снять точку и поставить заново. Кнопка **×** в панели удаляет выбранную линейку. Это кнопка интерфейса, а не клавиша X.

[Полное руководство](docs/USAGE_RU.md) содержит настройки единиц, подписи рёбер, ориентацию сечения и таблицу управления.

## Совместимость и ограничения

- Минимальная заявленная версия — **Blender 4.5.0**. Проверены **4.5.14 LTS** и **5.2.2 LTS**. Новые версии добавляются после проверки; автоматической гарантии совместимости со всеми будущими версиями нет.
- Линейки **временные**: не сохраняются в `.blend`, сбрасываются при загрузке файла, undo/redo и отключении расширения. Для задания запишите числа или сохраните снимок экрана.
- При смене топологии затронутый конец нужно выбрать заново; второй конец и другие линейки сохраняются.
- **d** — прямой отрезок между выбранными точками. **½** — половина измеренного размера; для произвольной формы это не радиус кривизны.
- Измеряются Mesh-объекты и доступные меш-инстансы Geometry Nodes. Quad View не поддерживается. Тяжёлые сетки ограничены для интерактивного измерения; подробности — в [FAQ](docs/FAQ_RU.md).

## Обновления и обратная связь

На [странице последнего выпуска](https://github.com/Ddosena/blender-final-dimensions/releases/latest) находятся ZIP и список изменений. Для обновления скачайте свежий ZIP, установите его тем же способом и перезапустите Blender, сохранив сцену. Установка с диска не включает автоматическое обновление из GitHub.

Нашли ошибку? [Создайте сообщение в Issues](https://github.com/Ddosena/blender-final-dimensions/issues/new/choose): шаблон подскажет, какие версии и шаги указать. Новые возможности можно предложить отдельным шаблоном.
