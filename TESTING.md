# Проверки и совместимость

Публичный выпуск: **Final Dimensions 0.6.0**, 06.10.2026.

## Ручная проверка Windows

| Blender | Проверено |
| --- | --- |
| **5.2.2 LTS** | Численные измерения, сечения, выбор поверхности, ZIP и установка, живой viewport. |
| **4.5.14 LTS** | Численные измерения, сечения, выбор поверхности, ZIP и установка, живой viewport. |

На обеих версиях прошли **19 сценариев нескольких линеек**: добавление без потери предыдущих, выбор через список, перетаскивание обоих концов, повторная установка каждого конца ПКМ с сохранением противоположного, переход между объектами, возврат при отпускании в пустоте, Esc, выключенные Overlays, независимое обновление привязок при смене топологии, перенос объекта, переход в другой viewport, удаление выбранной линейки и очистка обработчиков.

В версии 0.6.0 на обеих версиях прошли **17 сценариев snapping с реальными событиями мыши**: магнит Off/On, Original Vertex за пределами сглаженного силуэта, новые вершины Subdivision, смешанные Original/Final концы одной линейки, перетаскивание по Edge, замена точки по Face, независимость Original от изменения модификатора, смена источника без движения курсора, отсутствие подмены Vertex на Face, временное переключение Ctrl и очистка состояния.

Дополнительно прошли **7 групп численных проверок snapping**: настоящие рёбра без диагоналей триангуляции, свободные вершины/рёбра, перспективная интерполяция и clipping, скрытая и перекрытая геометрия, backface и фильтры целей, живой BMesh, Geometry Nodes instances, лимиты кеша и выбор ближней вершины при почти совпадающих проекциях. Установленная пользовательская копия 0.6.0 включена и побайтово совпадает с исходниками и ZIP.

Отдельно прошли 15 сценариев исходной линейки на 5.2.2 и численные проверки геометрии: модификаторы, преобразования, единицы, Geometry Nodes, направления и контуры сечений. В тестовых сценах исходные вершины и число мешей сохраняются. Установочный ZIP прошёл штатный `extension validate`; установка, отключение и повторное включение проверены на обеих версиях.

## Автоматические проверки GitHub

[Текущий результат GitHub Actions](https://github.com/Ddosena/blender-final-dimensions/actions/workflows/blender.yml).

Матрица запускает Blender **4.5.14** и **5.2.2** на Ubuntu 24.04. Численные тесты идут в фоне, сценарии мыши/GPU — под Xvfb с программным OpenGL. Статус каждой проверки относится к конкретному commit; результаты JSON, журналы, снимки и ZIP доступны в артефактах запуска в течение 14 дней.

macOS отдельно не проверялась. Успех автоматического Linux-теста не заменяет проверку на конкретной конфигурации студента. Для новых версий Blender нужна новая проверка; минимальная заявленная версия manifest — 4.5.0.

## Повторить проверку

Из корня проекта:

```powershell
python .\scripts\check_blender.py --blender '.\tools\blender-5.2.2-windows-x64\blender.exe' --gui
```

[Подготовка окружения и выпуск](docs/MAINTAINING_RU.md#проверки-и-сборка-на-windows).

Тесты меняют свои заводские сцены. Запускайте их указанным способом в отдельном процессе, не внутри рабочей сцены. Они не измеряют скорость на всех возможных моделях и не гарантируют совместимость с произвольной будущей версией API.

## Известные ограничения

Временные линейки не сохраняются в `.blend`. Смена топологии сбрасывает затронутый конец. Quad View и non-mesh компоненты не поддерживаются. Плотность поверхности ограничена для интерактивного расчёта; см. [FAQ](docs/FAQ_RU.md).

В отдельных локальных журналах Blender 4.5 при выходе встречались сообщения о неосвобождённой памяти. Причина не установлена; исключений API или увеличения числа исходных мешей в проверках не обнаружено.
