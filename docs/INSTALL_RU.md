# Установка Final Dimensions

Final Dimensions добавляет в Blender измерения размеров модели после модификаторов, сечения под мышью и линейки между точками поверхности. Устанавливать Python или дополнительные пакеты не нужно.

Инструкция использует английские названия интерфейса Blender; пояснения приведены по-русски. Минимальная версия — **Blender 4.5**. Расширение проверено в **4.5.14 и 5.2.2**. Более старые версии не поддерживаются; работа в остальных, включая более новые, пока не подтверждена.

## 1. Проверьте версию Blender

Откройте **Help → About Blender** («Справка → О Blender»). Найдите номер версии в открывшемся окне. Если он меньше 4.5, сначала установите подходящую версию с [официального сайта Blender](https://www.blender.org/download/). Закройте окно информации, чтобы продолжить.

## 2. Скачайте установочный ZIP

1. Откройте [ссылку на final_dimensions.zip](https://github.com/Ddosena/blender-final-dimensions/releases/latest/download/final_dimensions.zip). Она ведёт на установочный файл последнего опубликованного выпуска. Учётная запись GitHub для скачивания не нужна.
2. Дождитесь окончания загрузки. Обычно файл попадает в папку «Загрузки»; запомните, куда его сохранил браузер.
3. **Не распаковывайте ZIP.** Blender устанавливает расширение прямо из архива.

Можно также открыть [страницу выпусков](https://github.com/Ddosena/blender-final-dimensions/releases/latest), развернуть **Assets** и выбрать **final_dimensions.zip**. Не выбирайте **Source code (zip)** и **Code → Download ZIP**: это архивы исходников, а не подготовленный установочный пакет. Браузер может добавить к имени повторной загрузки `(1)` — это само по себе не мешает установке.

## 3. Установите файл в Blender

1. В верхнем меню Blender нажмите **Edit → Preferences…** («Правка → Настройки»). Откроется отдельное окно настроек.
2. В списке слева нажмите **Add-ons** («Дополнения»). Это раздел окна Preferences, а не панель Properties с настройками объекта.
3. В правом верхнем углу раздела Add-ons откройте выпадающее меню — небольшую кнопку со стрелкой вниз.
4. Выберите **Install from Disk…** («Установить с диска»).
5. В открывшемся файловом окне перейдите в папку, куда скачали архив, например «Загрузки».
6. Один раз нажмите на **final_dimensions.zip**, чтобы выделить его. Не заходите внутрь архива и не выбирайте отдельный файл `.py`.
7. Подтвердите установку кнопкой **Install from Disk** в файловом окне. Дождитесь завершения.
8. В поиске раздела **Add-ons** введите **Final Dimensions**. Если список ограничен флажком **Enabled Add-ons Only**, временно снимите его, чтобы увидеть и выключенные дополнения.
9. Найдите **Final Dimensions** и убедитесь, что рядом с названием стоит **галочка включения**. Если её нет, нажмите на пустой флажок. Установка файла и включение дополнения — отдельные действия.
10. Закройте окно Preferences.

В Blender 4.5+ Final Dimensions оформлен как **extension** («расширение»), которое добавляет **add-on** («дополнение»). Для пользователя используется то же окно установки из ZIP. Установка расширений из ZIP и включение флажком описаны в [официальном руководстве Blender: Add-ons](https://docs.blender.org/manual/en/4.4/editors/preferences/addons.html). Иллюстрации руководства для другой версии могут немного отличаться от вашего окна.

## 4. Найдите панель и проверьте установку

1. Вернитесь в **3D Viewport** — область, в которой видна модель.
2. Наведите мышь именно на эту область и нажмите **N** на клавиатуре. При необходимости переключитесь на английскую раскладку. Справа появится боковая панель; повторное N закрывает её.
3. На вертикальных вкладках панели выберите **Final Dimensions**. Если вкладки не помещаются, расширьте панель, потянув её левую границу влево.
4. Выберите обычный Mesh-объект, например стартовый куб. Раскройте блок **Object dimensions** внизу панели: в нём находятся **Cage**, **Final**, **Delta**, **%** и **Half** по осям X/Y/Z.

Если вкладки нет, проверьте галочку включения в Add-ons, версию Blender и то, что N нажато над 3D Viewport. Дополнительные решения — в [FAQ](FAQ_RU.md). Первые измерения — в [инструкции по использованию](USAGE_RU.md).

## Обновление

1. Сохраните рабочую сцену через **File → Save**. Запишите нужные результаты измерений: линейки не сохраняются в `.blend`.
   Закройте всплывающие панели и окно выбора цвета через Esc перед обновлением.
2. Скачайте свежий **final_dimensions.zip** по той же ссылке. Номер выпуска и список изменений доступны на [странице выпусков](https://github.com/Ddosena/blender-final-dimensions/releases/latest).
3. Повторите установку через **Edit → Preferences → Add-ons → Install from Disk…**, выбрав новый ZIP. Если Blender предложит подтвердить замену установленной версии, подтвердите её.
4. Проверьте галочку **Final Dimensions**. Закройте и снова откройте Blender, затем откройте сохранённую сцену: уже открытая сессия может удерживать прежний код в памяти.

Пакет устанавливается с диска, поэтому обновления следует скачивать вручную. Если замена не проходит, сохраните сцену, удалите прежнее расширение по инструкции ниже, перезапустите Blender и установите новый ZIP.

## Отключение и удаление

Для временного отключения откройте **Edit → Preferences → Add-ons**, найдите **Final Dimensions** и снимите галочку. Измерения исчезнут, список линеек очистится; модель останется в сцене.

Перед отключением закройте всплывающие панели и окно выбора цвета через **Esc**.

Для удаления откройте в Preferences раздел **Get Extensions**, найдите установленный **Final Dimensions**, откройте маленькое выпадающее меню справа в его строке и выберите **Uninstall** («Удалить»). Подтвердите удаление. Если фильтры скрывают установленное расширение, очистите поиск и включите показ установленных расширений.

Установочный ZIP в папке загрузок можно сохранить для повторной установки. Удаление ZIP само по себе не удаляет уже установленное расширение.
