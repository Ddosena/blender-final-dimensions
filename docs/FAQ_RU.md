# Вопросы и устранение проблем

| Что происходит | Что проверить |
| --- | --- |
| Не могу найти Add-ons | Откройте отдельное окно **Edit → Preferences**, затем раздел **Add-ons** слева. Редактор **Properties** с настройками объекта — другое место. В macOS расположение системного меню настроек может отличаться; ищите окно **Preferences** Blender. |
| Архив не устанавливается | Нужен **final_dimensions.zip** из Assets выпуска, целиком и без распаковки. **Source code (zip)** и **Code → Download ZIP** не подходят. Проверьте, что скачивание завершено и Blender версии 4.5 или новее. |
| Final Dimensions нет в списке | Очистите поиск и фильтры, снимите **Enabled Add-ons Only**, затем введите Final Dimensions. Повторите [установку](INSTALL_RU.md), если пакет не установился. |
| Нет вкладки Final Dimensions | Проверьте галочку включения в Add-ons. Наведите мышь на **3D Viewport**, нажмите **N** на английской раскладке. Вкладки находятся на правом краю боковой панели; расширьте её при необходимости. |
| Панель просит Select a mesh object | Выберите Mesh-объект, например куб. Таблица и сечение используют активный объект, а не все выделенные сразу. |
| Линии и подписи исчезли | Проверьте **Show Overlays** — значок двух пересекающихся окружностей в правом верхнем углу 3D Viewport. Для рёбер также проверьте **Selected edge labels**, для сечения — **Hover section**. |
| Нет e/f у ребра | В Edit Mode включите выбор рёбер клавишей **2 верхнего цифрового ряда** и выделите одно ребро. Если смотрите точно вдоль него, немного поверните вид. |
| Сечение наклонено или отсутствует | В Edge + surface выберите другое поперечное ребро; попробуйте **Plane: Local X / Y / Z**. Читайте пояснение панели: открытый контур или почти параллельные ребро и нормаль могут исключать измерение. |
| Линейка не ставит точку | Нажмите **Add Ruler**, затем кликайте по видимой Mesh-поверхности. Клик в пустоту не ставит точку. Проверяйте сообщение панели и ограничения тяжёлых мешей ниже. |
| Точка исчезла после изменения модели | Изменение топологии, скрытие или удаление объекта делает затронутую привязку недействительной. Выберите линейку и используйте **Pick Point 1 / 2**; другой конец и остальные линейки сохраняются. |
| После открытия файла или Ctrl+Z нет линеек | Это ожидаемо: временные линейки не сохраняются в `.blend` и сбрасываются при загрузке, undo/redo и отключении расширения. |
| Размеры отличаются от Item → Dimensions | Final Dimensions измеряет по мировым осям и учитывает модификаторы. Поворот меняет мировой габарит. Проверьте также **Scene Properties → Units** и Unit Scale. |
| После обновления вижу прежнее поведение | Сохраните сцену и перезапустите Blender: открытая сессия могла сохранить старый код. Проверьте номер установленного расширения в его информации в Preferences. |

## Нужен ли GitHub, Python или интернет для измерений?

Учётная запись GitHub не нужна для [скачивания установочного ZIP](https://github.com/Ddosena/blender-final-dimensions/releases/latest/download/final_dimensions.zip). Отдельно устанавливать Python или его пакеты не требуется: используется поставка Blender. После скачивания ZIP и установки для измерений подключение к интернету не нужно.

## Какая версия Blender подходит?

Минимальная версия — **4.5**. Проверены **4.5.14 и 5.2.2**. Более старые версии не поддерживаются. Для остальных версий, в том числе более новых, проверка ещё не выполнена; успешную работу обещать нельзя. Свой номер версии найдите через **Help → About Blender**.

## Нужно ли применять Subdivision, Bevel или другие модификаторы?

Нет. Расширение измеряет вычисленную геометрию с текущими настройками **Viewport**. Render Level у Subdivision может быть другим и здесь не используется. В Edit Mode Blender может исключить модификатор, выключенный для этого режима; панель предупреждает об этом. Если нужно сравнить результат, переключитесь в Object Mode и проверьте видимость модификатора во Viewport.

## Почему половина размера не совпадает с ожидаемым радиусом?

**Half** в таблице — половина мирового габарита Final по оси. **½** у сечения — D/2 в выбранном направлении. Для круглого сечения это может соответствовать привычному радиусу, но для произвольной формы не является радиусом кривизны, вписанной сферы или автоматически найденной толщиной стенки.

## Почему d не показывает минимальный зазор?

Линейка показывает прямое расстояние между двумя точками, которые вы выбрали. Она не ищет ближайшую пару точек двух объектов и не прокладывает путь по поверхности. Положение концов можно уточнить перетаскиванием или кнопками **Replace 1 / 2**. [Подробная инструкция](USAGE_RU.md#изменение-и-удаление-линейки).

## Можно ли сохранить линейки в сцене?

В версии 0.5.0 — нет. Список принадлежит текущему окну Blender и очищается при загрузке файла, undo/redo или отключении расширения. Закрытие N-панели не удаляет линейки. Для отчёта запишите числа или сделайте снимок экрана.

## Поддерживаются ли Geometry Nodes и несколько объектов?

Измеряются Mesh-объекты и доступные через Blender меш-инстансы Geometry Nodes. Non-mesh компоненты — например кривые или объёмы — не входят в эти измерения; предупреждения видны в панели. Таблица габаритов и сечение относятся к одному активному Mesh. Линейка может соединять поверхности двух разных видимых объектов. Общий габарит всех выделенных объектов не реализован.

## Почему большая модель измеряется медленно или не измеряется?

Тяжёлые модификаторы и плотная сцена замедляют вычисления. Для одной поверхности интерактивного сечения или линейки установлен предел **350 000 вершин / 700 000 треугольников**. Общий кеш линеек также ограничен: до **32 поверхностей**, **700 000 вершин / 1 400 000 треугольников**. При превышении лимита смотрите сообщение в панели. Попробуйте уменьшить уровень Subdivision **Viewport** или временно скрыть ненужные объекты; это меняет доступную для измерения геометрию, поэтому оцените результат заново. В режиме **Quad View** сечения и линейки не поддерживаются — используйте один обычный вид.

## Как обновить или удалить расширение?

Следуйте разделам [обновления и удаления](INSTALL_RU.md#обновление). Для установки из ZIP обновления скачиваются вручную. Официальное описание **Install from Disk** и включения дополнений есть в [руководстве Blender](https://docs.blender.org/manual/en/4.4/editors/preferences/addons.html).

## Как сообщить об ошибке?

Откройте [Issues проекта](https://github.com/Ddosena/blender-final-dimensions/issues/new/choose). Для отправки сообщения потребуется учётная запись GitHub. Укажите:

- версию Blender из **Help → About Blender** и версию Final Dimensions;
- что вы делали по шагам и какой результат ожидали;
- что получилось и точный текст предупреждения в панели;
- режим Object/Edit Mode, нужные модификаторы и их настройки Viewport;
- снимок экрана или минимальную тестовую сцену, если можете ею поделиться.

Перед публикацией уберите из снимков и сцены личные данные и материалы, которые нельзя распространять. Не требуется прикладывать всю рабочую сцену: маленький пример обычно проще проверить.
